# STDISCM_P4

## Install all dependencies
1. Install all python dependencies using the requirements.txt.
2. Install the node dependencies by changing the directory to "frontend" and executing npm install.

## Run the Server
1. Run the server via the following command: python -m backend.gateway.run_all

## Run the Client
1. Run the client via the following command: cd frontend | npm run dev

# Run the Model
1. Run the model via the following command: python -m backend.clients.train_realtime_torch
